# Ejercicio_grupal_2

Para poder ejecutar:
1. Crear el archivo .env que contenga: API_KEY=[TU API_KEY] 
2. Poner en la terminal flutter pub get. De esta forma, se descargan las dependencias de pubspec.yaml

Posibles problemas
-

- Hay que ir a la documentación de Gemini para revisar el modelo de gemini. Actualmente usamos gemini-3-flash-preview pero por si acaso: https://ai.google.dev/gemini-api/docs?hl=es-419
- Para emular en windows, he tenido que cambiar la dirección de la carpeta del proyecto: el Windows Builder se confunde si hay tildes, espacios y todo eso
